# Anthropic IPO 路演文件拆解：贵不贵、险在哪、澳洲怎么参与

> **⚠️ 本页不构成任何投资建议。** 内容是对公开文件的整理和个人观点，可能有错漏，以官方招股书为准。投资有风险，可能损失全部本金，决策前请自己读完原文，必要时咨询持牌顾问。
>
> 2026-11-12 · 数据来自 Anthropic 官方路演 PPT、创始人信和澳洲招股书（ASIC 备案，542 页）。观点单独标出。

**一句话：** 增长和效率是真的，第三季度已经开始赚现金。但这次是按万亿美元定价，背后压着约 9000 亿美元的算力合同，增速也在放慢。这次 IPO 买的是一个「增长曲线会一直陡下去」的赌注，不是一家成熟公司。

## 1. 发行条款

- 发行 8.25 亿股 Class A（公司发 8.01 亿股，老股东卖 2365 万股），每股 $70–78，纳斯达克上市，代码 **ANT**；承销商另有 1.2375 亿股超额配售权。
- 同时 AMD、Broadcom、Google、Micron、Microsoft、Nvidia、TSMC 按 IPO 价买入 **$26B** 无投票权的 Class N 股（Google 和 Nvidia 各 $10B）。
- 公司净募资：按中间价算约 $84.6B（含超额配售约 $93.7B）。
- **估值有两种口径：** 按中间价 $74，Class A 加 Class N 的市值约 **$968B**（澳洲招股书第 22 页）；媒体报的 **$1.404T** 是按上限价、完全稀释口径算的。看新闻时要分清。
- 募资用途：一般经营用途，主要是算力和人才；另有约 $3.8B 用来缴员工 RSU 结算的代扣税。

## 2. 财务

| 指标 | 数字 |
|---|---|
| Q3'26 收入 | $17.0B，同比超过 12 倍 |
| 季度收入轨迹 | $0.4B → 0.8 → 1.4 → 2.0 → 4.7 → 11.6 → 17.0（Q1'25 到 Q3'26） |
| 环比增速 | Q1 +132%，Q2 +144%，**Q3 +47%** |
| 年化收入（run-rate） | 10 月底约 **$81B**，比 9 月底多 $10B |
| Q3 经营利润率 | GAAP 是 **-3%**，调整后是 **+15%** |
| 前 9 个月经营现金流 | **+$6.6B**（去年同期 -$2.0B） |
| Q3 净亏损 | $23.3B，其中 $21.9B 是估值上涨带来的非现金公允价值变动 |
| 算力效率 | 收入除以算力成本，比 Q1'25 提升超过 4 倍 |
| 收入结构（上半年） | 按用量计费 80%，订阅 20% |
| 人效 | 过去 12 个月人均收入超过 $6.6M |

**客户：** 年付超过 $100K 的客户有 11,900 多家（一年前约 950 家），超过 $1M 的约 1,900 家，超过 $10M 的约 250 家；净收入留存率约 900%；Fortune 500 里超过一半在用。前五大客户占收入约 25%，单一客户不超过 10%，不少没有长约，可以随时减少用量。

## 3. 最大的风险：算力合同

- 算力承诺约 **$900B**，其中 $451.6B 在 2030 年前到期，其余大多在 2031–2045 年；**未来 12 个月要付 $70.7B**。
- 账上现金约 $96B，短期投资约 $36B，另有 $15B 信贷额度。
- PPT 脚注自己承认：Q3 临时买了 $5.0B 的短期算力，价格「显著高于」长约，抵消了一部分效率提升。说明需求超出了预期、只能高价补；反过来，如果需求哪天跟不上，这些合同会变成很重的负担。
- 创始人信也直说会「看起来不负责任地」大举超前投入算力，拿制药行业先砸研发再回本作类比。

## 4. 治理：买 Class A 基本没有话语权

- 7 位联合创始人通过一家 LLC 持有一股 Class F，**固定拿 50.1% 的投票权**；等在任的创始人少于 3 位时，这部分投票权才转回普通股东。
- 长期利益信托（LTBT）通过 Class T 选 7 席董事里的 4 席；LTBT 受托人没有经济利益，也不准持股。
- 公司是公益公司（PBC），董事会要在股东利益和公益使命之间权衡；不分红。
- IPO 前已经拿出 5% 股权放进 Anthropic 公益基金；以后股价每持续涨 50%，董事会可以酌情再拿出 2%（会有稀释）。
- 7 位创始人都承诺捐出个人股权的 80%。

## 5. 创始人信：一份「劝退书」

信里明确写了哪些地方会和「利润最大化」的预期不一样：
- **会为安全主动放慢进度**，「即使这让我们处于竞争劣势」；举的例子是 Mythos 当年没有直接公开发布，等加了防护才以 Fable 5 推出，放弃了大量收入。
- **不做广告**，理由是一旦广告进了收入目标，就会有优化用户参与度的压力。
- 会花更多精力开发新产品，而不是守住现有产品。
- 引了别人给他们的一句话：「never let your company be worth a dollar more than it is actually worth」（别让公司的估值比它实际值的多一块钱）。

## 6. 解禁（影响上市后的股价）

- 一般锁定期 180 天；创始人和持股超过 0.5% 的大股东锁 365 天。
- 员工、非创始人董事和高管手里最多 **10% 的锁定股，上市第一天就能卖**；180 天内总共约 36 亿股可能提前解禁。
- 战略投资方买的 Class N 股**不受承销商锁定约束**，但属于受限证券，转售要走注册或豁免。
- Amazon 和 Google 上市后各持股超过 5%。

## 7. 澳洲居民怎么参与（流程说明，不是建议）

- 只能通过券商申购（Broker Firm Offer）。牵头的是 **CommSec**，需要开通国际股票账户；官网还列了 Macquarie、Morgan Stanley、Bell Potter、Morgans、Stake、Sharesies 等。
- 时间（AEDT）：11/11 开放 → **11/17 下午 5:00 截止** → 11/19 定价 → 11/20 纳斯达克开盘 → 11/21 交割。券商可能更早截止。
- 要注意的几点：
  - **申购时还不知道最终价格**，定价在区间以外也要照单全收，区间本身也可能调整；
  - 没有最低和最高申购额，可能只分到一部分，甚至一股都没有；
  - 用美元计价，用澳元付款有汇率风险，退款也可能有汇兑损耗；
  - 申购本身没有佣金和印花税，但券商可能收换汇费；
  - **利益冲突：** CommSec 的母公司 CBA 自己持有 Anthropic 股份（不到 0.5%）；
  - 澳洲的收购法不适用，以后的增发也不保证让澳洲股东参与；股息有美国预扣税，具体税务问题请问专业人士。

## 8. 我的看法（观点，不构成投资建议）

1. **估值算贵但不离谱。** 约 $968B 对应 $81B 年化收入，大约 12 倍。增速守得住，这个价说得通；如果 Q4 环比再掉到 20–30%，市场会马上按「普通高增长软件公司」重新定价。
2. **决定成败的是增速，不是模型。** 9000 亿的算力合同已经签死了，收入曲线必须一直陡下去。Fable 5.2 跑分第一，但官方自己都劝日常先用 Opus 5.5，高端模型的溢价并不好收。
3. **时机不好。** 上周 AI 板块大跌，纳指一周跌了 5.5%，Nvidia 那边又在内部调查。上市头几周情绪的影响会比基本面大。
4. **上市第一天就有员工抛压**，再加上 Class N 不受锁定约束，开盘后的价格波动可能很大。
5. **治理结构是双刃剑。** 安全上的承诺是真的，但这意味着小股东没有发言权；信里已经提前说了，以后可能会「为了安全放慢」。认同这一点再考虑，不认同就别碰。
